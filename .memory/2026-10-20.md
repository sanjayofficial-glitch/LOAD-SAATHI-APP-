# 2026-10-20 — Theme locked to light

**Task:** DevTools diagnostics showed `html.dark` + `color-scheme: dark` causing light-on-light text visibility issues. User chose **lock light permanently** (option A): dark mode is no longer reachable via stored prefs, OS setting, or toggle.

## Root cause chain

- 2026-10-19's change made light the *default* for new visitors, but stored `'dark'`/`'system'` values in localStorage (`loadsaathi-theme`) still won on load — the pre-paint boot script (`index.html`) and `readStoredMode()` honored them, so returning users stayed dark.

## What was changed

- **`supabase/src/theme/theme.tsx`** — rewritten as a light-locked provider: `ThemeMode = 'light'` only, `isDark: false` always, setters/toggle are documented no-ops, one mount effect strips `dark` class / sets `data-theme=light` / `color-scheme=light` / `theme-color=#ea580c` and removes the legacy localStorage key. Context API shape unchanged so consumers (e.g. `ThemedToaster` in App.tsx) compile untouched.
- **`index.html`** — boot script no longer reads localStorage or `prefers-color-scheme`; it force-normals light and clears `loadsaathi-theme`. `<meta name="color-scheme">` is now `light` (was `light dark`). Removed the `@media (prefers-color-scheme: dark)` + `html.dark` boot-loader style overrides.
- **ThemeToggle deleted** — removed from `PublicLayout`, `Layout` (incl. the `#layout-theme-toggle` span anchor; nothing at runtime references it — only an old `.kilo/plans` doc), `Login`, `Register`. Component file `supabase/src/components/ThemeToggle.tsx` deleted.
- **Docs synced:** `CONTEXT.md` (Theme State + troubleshooting), `docs/architecture.md`, this file.
- Left alone: `.dark` selectors in `globals.css` (dead styles now — dark is inert), `freddy-avatar/index.html` (`:root { color-scheme: dark }` — standalone avatar artifact, not the app shell), manifest (already light `#ffffff`/`#ea580c`).

## Rules for future sessions

- Do not re-add dark-mode code paths — the app is intentionally light-locked.
- `pnpm typecheck` + `pnpm test` + `npx vite build` are the fast verification trio (full `pnpm build` runs live-network prerender/smoke and times out).
