Ask · me

Ask me — question recipes that work

Copy-paste these patterns. Replace the bracketed part. I read code; you get plain words.

Explain: "Explain [matching.ts / credit score / escrow flow] like I'm a PM — what the user sees, what can go wrong, what I'd measure."
Impact: "If we change [review policy / matching weights / fees], what breaks? List affected screens, tables, and users."
Compare: "Compare [shipper vs trucker dashboard] — every widget, what's missing for each?"
Funnel: "Map the funnel for [request → accept] — every state, every drop-off, what to instrument."
Review a change: "This PR touches [paste files or link] — what user-visible behavior changes, and what's the risk?"
Write it: "Turn [this decision] into a one-page PRD: problem, users, scope, metrics, risks."
Quiz me: "Quiz me on [matching / trust / money] — 5 questions, then grade me."
How to get good answers: name the feature + the decision ("…because I'm considering raising the trucker fee"). One question per message. If my answer has jargon, reply "simpler" — I'll redo it with zero technical terms.

First-week plan

Your 5-day tool sequence

  1. Day 1 — Orient: Visual Guide §1–§3 (30 min) → Dashboard Tour × 12 (20 min) → write your one-page user/journey summary.
  2. Day 2 — Feel: Live site dual-role walkthrough (1 hr) → log 5 frictions → ask me "why does [friction] exist?"
  3. Day 3 — Brain + trust: Dashboard search matching + CreditScore (1 hr) → ask me to explain weights and score recovery.
  4. Day 4 — Data + money: Database Live Visual full play (25 min) → read pricing.md → map the funnel with real numbers.
  5. Day 5 — Decide: Pick one gap from the Brief §12 → ask me for impact + PRD → present it. You've now done a full PM loop.
